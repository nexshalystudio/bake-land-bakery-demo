# Bake Land Bakery — website demo

A responsive, single-page bakery website built with plain HTML, CSS and JavaScript. This version is a demo populated with Bake Land Bakery's publicly provided listing details.

## Preview locally

Open `index.html` in a browser. Google Fonts and the food photography load from external services, so those assets need an internet connection.

## Customize for a customer

Before delivering a copy, update the bakery name and Malayalam name, phone number, address, opening hours, menu items, review quotes, map links and page description in `index.html`. Adjust colors and layout in `styles.css`. Replace the Unsplash image URLs in `styles.css` with images the customer has permission to use. Remove or replace the sample reviews unless the customer has approved their use.

Check every `tel:` and Google Maps link after changing the business details. This is a static front end: online ordering, payments, booking, and a content management system are not included.

## Publish with GitHub Pages

1. Create a repository on GitHub and upload these project files.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. GitHub will show the published URL in the Pages settings when deployment finishes.

## Customer delivery and rights

This repository does not include a license granting resale or redistribution rights. Choose and add a license that matches how you plan to sell and support customer copies. Confirm that you have permission to use each customer's branding, photos and review text. The linked Unsplash photos are remote demo assets; verify their current license and suitability before using them in a paid customer site.
